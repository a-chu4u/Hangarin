## 📌 About

**Hangarin** is a Django-based web application designed to help users organize and manage their daily tasks. It allows users to set priorities, categorize tasks, add notes, and break down larger goals into smaller subtasks — all in one place.

---

## ✨ Project Features

- 📝 **Task Management** — Create and manage tasks with titles, descriptions, deadlines, and status.

- 🚦 **Priority Management** — Organize tasks according to priority levels such as High, Medium, Low, Critical, and Optional.

- 📂 **Category Management** — Group tasks into categories such as Work, School, Personal, Finance, and Projects.

- 📋 **Subtask Management** — Break larger tasks into smaller and more manageable subtasks.

- 🗒️ **Notes** — Add notes and additional information to individual tasks.

- 🔄 **Task Status** — Track tasks using Pending, In Progress, and Completed statuses.

- 🎲 **Fake Data Generation** — Use Faker to generate sample tasks, notes, and subtasks for testing.

- ⚙️ **Django Admin** — Manage tasks, categories, priorities, notes, and subtasks through a customized admin interface.
